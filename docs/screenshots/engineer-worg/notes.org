* Design system
  Our components follow the [[file:work.org::*Build the component library][component library]] plan.
  Colours come from a single token file so light and dark themes stay in step.

** Colour tokens
   | Token      | Light   | Dark    | Use                  |
   |------------+---------+---------+----------------------|
   | surface    | #ffffff | #1b1d22 | page background      |
   | ink        | #1f2328 | #e6e6e6 | body text            |
   | accent     | #2f6feb | #6ea8fe | links, focus rings   |
   | danger     | #cf222e | #ff7b72 | destructive actions  |

** Spacing
   Everything sits on a 4px grid. See [[*Colour tokens][Colour tokens]] for the palette.

** Fibonacci in Go
   #+BEGIN_SRC go
   func fib(n int) int {
       if n < 2 {
           return n
       }
       return fib(n-1) + fib(n-2)
   }
   #+END_SRC
** Quick http server

       s.serve_forever()
   #+END_SRC
