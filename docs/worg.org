* What worg is

  worg is the web front end built into the server: =orgs serve= hands it out at
  =/=, so any browser that can reach the server (a phone included) has it. It
  works on the same notes as the command line and the editor plugins; a change
  made in one is in the others a second later.

  It has a light and a dark look, picked with the moon in the top corner.

  [[file:images/worg-agenda-dark.png]]

  The pictures here are of the demo notebook in =docs/screenshots/demo=, taken
  by =tools/screenshots= (see [[*Taking the pictures again][Taking the pictures again]] in the command line tour).

* Agenda

  The day as a planner: habits at the top, the hours of the day with what is
  booked into them, and the tasks still to place down the side, most urgent
  first. Drag a task onto an hour to schedule it. Week and Month show the
  wider view; the calendars mark days with something on them.

  [[file:images/worg-agenda.png]]

** Agenda views

   Above the calendar, a picker of custom agenda views: org's own (=a= the
   week, =t= open tasks, =n= both, =#= stuck projects), the server's yaml,
   and your own. A view shows its sections one after another, and an item
   opens as the calendar's do. =orgs agenda -view= prints the same views.

   [[file:images/worg-agenda-views.png]]

* Search

  The query language in a form: an expression, a regular expression over the
  text, and filters by keyword, tag and property. Rows can be edited where
  they are; Inspect opens a heading's dates, drawers and body beside the
  table.

  [[file:images/worg-search.png]]

* The command palette

  ⌘K (ctrl-K) anywhere: every tab, capture template, file, saved search and
  setting, and any heading in your notes, found by typing a few letters.

  [[file:images/worg-palette.png]]

* Clock Report

  Org's clock table as a page: what you are clocked into, then the time
  clocked over a range, heading by heading.

  [[file:images/worg-clock-report.png]]

* Files

  Every org file, read rendered or as org, and edited in place. Drawers fold,
  links follow, and the Links panel shows what points at the file and what it
  points at.

  Pictures a file links to are drawn under their links in the Org view and in
  the editor, as Emacs does with =org-display-inline-images=. The picture
  button on the toolbar (*Images* on the editor's status line) shows or hides
  them all; an eye at the end of a link's line, there when the pointer is,
  shows or hides that one. Click a picture to see it full size.

  [[file:images/worg-files.png]]

  [[file:images/worg-inline-images.png]]

** Editing

   *Edit* turns the Org view into an editor with vim or Emacs keys and org's
   own commands: folding, moving subtrees, cycling keywords and priorities,
   scheduling. See [[*Editing org files in worg][Editing org files in worg]] for every key.

   [[file:images/worg-editor.png]]

** Links and backlinks

   The links panel beside the page shows what links to the heading being read,
   what it links to, and where its title is written but not yet linked.

   [[file:images/worg-links-panel.png]]

** Refiling and archiving

   *Move headings* ticks headings in the file and refiles, copies or archives
   them, as =C-c C-w= and =C-c C-x C-a= do.

   [[file:images/worg-refile.png]]

** Transclusion

   A =#+transclude:= line draws the heading, file or lines it names, as
   org-transclusion does, in the rendered page and every export; the file
   keeps the one line. Each transclusion has a bar naming its source, and
   *Edit source* writes a change back into the file it came from. The page
   draws again when a source changes. It is off until it is turned on in the
   settings menu (or with =orgs transclude on=).

   [[file:images/worg-transclusion.png]]

** Citations

   =[cite:@key]= citations are set out, and =#+print_bibliography:= lists the
   works cited, from the file's =#+bibliography:= or the server's (the
   Citations guide has the details). Typing =@= inside =[cite:= in the editor
   offers the keys.

   [[file:images/worg-citations.png]]

* Kanban

  Boards built from a saved query, one column per keyword (or per tag or
  property value). Dragging a card to another column changes the heading in
  its file.

  [[file:images/worg-kanban.png]]

* Gantt Chart

  A saved query as a schedule: =EFFORT= sizes the bars, =AFTER= and =ORDERED=
  chain them, today is the red line. Bars can be dragged to reschedule,
  coloured by state, person or any property, and split into lanes.

  [[file:images/worg-gantt.png]]

* Column View

  org's column view of a file, from its =#+COLUMNS:= line, with totals on each
  parent. Any cell can be edited in place.

  [[file:images/worg-columns.png]]

* Tables

  Every org table, opened as a spreadsheet. Formulas (=#+TBLFM=) are shown and
  recalculated, cells are edited in place, and a selection can be charted.
  See [[*Tables][Tables]] for the formula language.

  [[file:images/worg-tables.png]]

  A table with a =#+PLOT:= line opens on its chart (ctrl-G), as org-plot
  would draw it.

  [[file:images/worg-chart.png]]

* Mind Map

  A saved query drawn as a map, coloured by branch, keyword or tag, and
  exported as an image.

  [[file:images/worg-mindmap.png]]

* Starmap

  Every heading as a star and every link as a thread between them, with a
  timeline to watch the notes grow.

  [[file:images/worg-starmap.png]]

* Contacts

  Headings with a =RECORD= property, as an address book: upcoming birthdays at
  the top, a vCard import, and each contact's fields and notes beside the
  list. See [[*Records — the contact book, and everything else worth a list][Records]].

  [[file:images/worg-contacts.png]]

* Collections

  The same view over any other kind of record: books, wine, recipes.

  [[file:images/worg-collections.png]]

* Flashcards

  Spaced repetition over your notes, org-drill compatible. A deck is a query;
  clozes hide part of a line until you ask for the answer. See
  [[*Flashcards — drilling your notes, org-drill style][Flashcards]].

  [[file:images/worg-flashcards.png]]

* Weekly Review

  GTD's weekly review as steps: empty the inbox one item at a time (refile,
  schedule, tag, archive, done), then the projects with no next action, what
  is waiting on others, last week's time and the stale scheduled items.

  [[file:images/worg-review.png]]

* Code

  Every source block in your notes, by language, with syntax colouring; a block
  can be run and its results written back under it.

  [[file:images/worg-code.png]]

  [[file:images/worg-code-run.png]]

* Focus: the timer

  Under the pomodoros, org's relative timer (=org-timer=): start it at the
  start of a meeting, or count down, and a note taken in it is written under
  the heading you are clocked into, stamped with the timer, as
  =org-timer-item= writes it. The server keeps the timer, so =orgs timer=
  sees the same one.

  [[file:images/worg-timer.png]]

* Tabletop games

  The dice button on the rail opens the tabletop tools: a random generator
  (encounters, treasure, NPCs, traps...), a dungeon generator you can draw on,
  and a map generator for regions, worlds and towns. A saved dungeon or map
  opens in the Files tab as a DM screen, with fog of war, tokens, an
  initiative tracker and a players' screen for a second display; a character
  file opens as its character sheet. The D&D guide has the whole tour.

  [[file:images/dnd-dm-screen.png]]
