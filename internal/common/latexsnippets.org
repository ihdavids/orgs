#+TITLE: Latex snippets
#+STARTUP: showall

The built-in maths snippets of orgs (=features: latexSuite:=), after
Emacs's cdlatex. Copy any row into your own
=latex-snippets.org= (=orgs latex init= writes one) to change it: a row of
yours with the same trigger and modes replaces the built-in one, and a row
with an empty replacement turns it off.

- Options :: =t= text, =m= any maths, =n= inline maths only, =M= display maths
  only (none of these: anywhere); =A= expands as you type (otherwise on TAB);
  =r= the trigger is a regular expression (matched against what comes just
  before the cursor; =[[0]]= is its first group); =w= not straight after a letter; =v= wraps the selection (=${VISUAL}=).
- Replacement :: =$1=, =$2=... are the places TAB visits in turn, =${1:x}= one
  with =x= written in it, =$0= where the cursor ends (the end, if there is
  none). The same number twice is typed in both places at once.
  In a cell =\vert= is a =|= and =\n= (not before a letter) a new line.
- Nothing expands while you type a command's name: =\sqrt= typed out stays
  =\sqrt=, though =sq= is a snippet.
- A trigger starting with =@= also expands after cdlatex's backquote: =`a= is
  =\alpha= as =@a= is.
